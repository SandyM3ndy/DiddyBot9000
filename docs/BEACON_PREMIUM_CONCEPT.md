# Beacon — First Paid Offerings (planning only)

> No premium features, purchases, subscriptions, entitlements, or paywalls have been shipped.

## Free Forever
- Existing core moderation, anti-nuke, emergency lockdown, verification and essential ticket workflows.
- Standard application system, giveaways, leveling, economy, and music where service capacity permits.
- Basic server setup and logging. Do not remove existing v1.0 capabilities without communicating a migration plan.

## First idea: Beacon Pro (pilot)
- **Suggested test price:** AUD $4.99 per server per month, subject to feedback and costs.
- Candidate value: configurable ticket branding, searchable transcripts with clear retention controls, richer ticket response metrics, advanced server activity reports, automated digest exports, configurable scheduled announcements.
- Keep security-critical actions, safety warnings, appeals and account access in the free tier.
- Initially recruit a small group of volunteer server owners to test the feature set; validate support/storage costs before launch.

## Alternative: Beacon Supporter
- Optional contributions through a reputable payment provider; no moderation advantage or gameplay pay-to-win benefits.
- Supporter badge on public release notes, community supporter role, early feature previews.
- Suggested test price: AUD $2.99 per month; donations should never imply the user is buying guaranteed features or privileged data access.

## Payments and eligibility
- Approval on **Top.gg** is not the same as app verification from Discord.
- Discord's published Premium Apps documentation currently lists supported developer locales as the US, UK and EU; Australia is not listed. Confirm eligibility in the Developer Portal before claiming native Discord subscriptions are available.
- Discord's developer guidance says outside payment services can be used where its native Premium Apps are not supported. Check the then-current Developer Policy before launch and respect its price-parity rules if native monetization later becomes available.
- Payments need clear cancellation, refunds, invoices and entitlement expiry, with no secrets/payment details collected through Discord messages.
- Plan data retention, deletion and export before offering premium transcript storage.

## Implementation gate
Do not ship paid entitlements until the security audit passes, the application/ticket workflows are regression-tested, and a basic subscription/entitlement test suite exists.
